In order to use the fully developed prototype of the app, each section will have its own README which can be used to give instructions to run the prototype. 

Due to the nature of prototype the database that is provided is to be run locally due to the limited set of data used which still enables the app to show full functionality.
A testing section has been added to the base git level which itself contains some of the unit testing used for each of the front end backend and database. The collaborative integration testing also has been added to the testing section.

The database section has its own instructions on how it is run locally with the use of MySQL

The frontend was made using an expo app and so its README contains instructions to run that app. 

The routing section was incorporated into the backend during the development of the prototype and so should be ignored when running the program as the routing algorithm is completely calculated in the backend.

In order to have a better understanding of what each component is and how you can run each component, please check the individual README.md files in each sub-folder of the repository.
